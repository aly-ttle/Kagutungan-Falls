# Kagutungan Falls Website

A responsive tourism website for Kagutungan Falls in Barangay Daligan, Santa Cruz, Ilocos Sur.

## Live website

After GitHub Pages is enabled, the website will be available at:

`https://aly-ttle.github.io/Kagutungan-Falls/`

## Pages

- `index.html` — Home
- `about.html` — About the falls
- `gallery.html` — Photo gallery
- `how-to-get-there.html` — Travel guide
- `contact.html` — Contact page

## Run locally

Open `index.html` in a web browser. No build process or package installation is required.

## Publish with GitHub Pages

1. Push this project to the `main` branch of GitHub.
2. In the GitHub repository, open **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait a few minutes, then open the live website link above.
